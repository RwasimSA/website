صفحة هبوط بسيطة تعلن أن الموقع قيد الإنشاء، مع شعار الجمعية الرسمي وبيانات التواصل.

## المحتويات

يُنشر محتوى `public/` فقط. ما عداه ملفات مستودع لا تصل إلى الويب.

| الملف | الوصف |
| --- | --- |
| `public/index.html` | الصفحة كاملة (HTML + CSS مدمج، بدون أي اعتماديات عدا خط Tajawal) |
| `public/assets/logo-mark.png` | **الشعار الرسمي كما هو** (8000×4500، خلفية شفافة) — المصدر، لا يُعدّل |
| `public/assets/logo.png` | نسخة الويب من الشعار (1400px، مقصوصة الهوامش) — تُستخدم في الوضع الفاتح |
| `public/assets/logo-dark.png` | نسخة معكوسة للوضع الليلي (الحبر الكحلي → فاتح، البرتقالي كما هو) |
| `public/assets/favicon.png` | أيقونة المتصفح (512×512) |
| `wrangler.jsonc` | إعداد نشر Cloudflare Workers |

## المواصفات

- عربية بالكامل مع اتجاه `rtl`.
- تصميم متجاوب (جوال / لوحي / سطح مكتب).
- دعم الوضع الليلي تلقائيًا عبر `prefers-color-scheme`، وتبديل نسخة الشعار عبر `<picture>`.
- روابط تواصل مباشرة: `mailto:` للبريد و `tel:` للهاتف.
- احترام `prefers-reduced-motion` لتعطيل الحركة عند الحاجة.

## التشغيل والنشر

الصفحة ثابتة بالكامل بلا خطوة بناء — يكفي فتح `public/index.html` مباشرة.

النشر عبر **Cloudflare Workers** مع الأصول الثابتة، بإعداد `wrangler.jsonc`. لا يوجد كود Worker
ولا حقل `main`؛ Workers يقبل مشروعًا مكوّنًا من أصول ثابتة فقط.

`assets.directory` يشير إلى `./public` وليس جذر المستودع — وهذا مقصود: لو أشار إلى الجذر
لأصبح `.git` وبقية ملفات المستودع ضمن ما يُنشر على الويب.

للتحقق من الإعداد محليًا بدون نشر:

```
npx wrangler deploy --dry-run
```

## تحديث الشعار

(`logo.png` و `logo-dark.png` و `favicon.png`) — وهي مجرد قصّ للهوامش وتصغير، مع عكس لون
الحبر غير البرتقالي في النسخة الليلية.
