# موقع جمعية رواسم لتنمية الطفل

الموقع الرسمي لجمعية رواسم لتنمية الطفل — جمعية سعودية مرخصة برقم (5170)، متخصصة في تنمية الطفل عبر برامج تربوية وقيمية ومهارية.

## التقنيات

- **React 18 + Vite 6** — واجهة تفاعلية عربية بالكامل (RTL).
- **Tailwind CSS 4** + أنماط زجاجية مخصصة بهوية الجمعية (`#0E4156` كحلي / `#EF9122` برتقالي).
- **Framer Motion** — حركات الأقسام والبطاقات.

## بنية المستودع

| المسار | الوصف |
| --- | --- |
| `src/` | كود المصدر (الأقسام، الصفحات، المكوّنات) |
| `static/` | الملفات العامة المصدرية (صور، خطوط، فيديو) — تُنسخ كما هي عند البناء |
| `public/` | **ناتج البناء** — الموقع النهائي الذي يُنشر (لا يُعدَّل يدوياً) |
| `wrangler.jsonc` | إعداد النشر على Cloudflare Workers (ينشر `public/` كأصول ثابتة) |
| `docs/خطة-محتوى-الموقع.txt` | خطة المحتوى المعتمدة لكل الشاشات |

## التطوير محلياً

```bash
npm install
npm run dev        # خادم التطوير على http://localhost:5173
```

## البناء والنشر

```bash
npm run build      # يبني الموقع إلى public/
```

النشر عبر Cloudflare Workers المربوط بالمستودع: كل دفعة إلى `main` تتضمن `public/` مبنيّاً تُنشر تلقائياً. **ابنِ قبل الدفع** حتى يعكس المنشور آخر تعديلات المصدر.
