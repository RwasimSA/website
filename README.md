# موقع جمعية رواسم — صفحة الهبوط المؤقتة

صفحة هبوط بسيطة تعلن أن الموقع قيد الإنشاء، مع شعار الجمعية وبيانات التواصل.

## المحتويات

| الملف | الوصف |
| --- | --- |
| `index.html` | الصفحة كاملة (HTML + CSS مدمج، بدون أي اعتماديات عدا خط Tajawal) |
| `assets/logo-mark.svg` | شعار "رواسم" كملف SVG مستقل |
| `assets/favicon.svg` | أيقونة المتصفح |

## المواصفات

- عربية بالكامل مع اتجاه `rtl`.
- تصميم متجاوب (جوال / لوحي / سطح مكتب).
- دعم الوضع الليلي تلقائيًا عبر `prefers-color-scheme`.
- روابط تواصل مباشرة: `mailto:` للبريد و `tel:` للهاتف.
- احترام `prefers-reduced-motion` لتعطيل الحركة عند الحاجة.

## التشغيل

الصفحة ثابتة بالكامل — يكفي فتح `index.html` مباشرة، أو رفع محتوى المجلد على أي استضافة ثابتة
(GitHub Pages، Netlify، Vercel، أو استضافة عادية).

## ملاحظة حول الشعار

الشعار هنا مرسوم يدويًا كمسارات SVG لمطابقة هوية الجمعية (نفس الأحرف والألوان:
`#123E54` و `#F09A28`). عند توفّر ملف الشعار الرسمي، يُستبدل محتوى `assets/logo-mark.svg`
وكذلك كتلة `<svg>` داخل `index.html` (تحت التعليق `شعار جمعية رواسم`).
