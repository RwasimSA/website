# موقع جمعية رواسم — صفحة الهبوط المؤقتة

صفحة هبوط بسيطة تعلن أن الموقع قيد الإنشاء، مع شعار الجمعية الرسمي وبيانات التواصل.

## المحتويات

| الملف | الوصف |
| --- | --- |
| `index.html` | الصفحة كاملة (HTML + CSS مدمج، بدون أي اعتماديات عدا خط Tajawal) |
| `assets/logo-mark.png` | **الشعار الرسمي كما هو** (8000×4500، خلفية شفافة) — المصدر، لا يُعدّل |
| `assets/logo.png` | نسخة الويب من الشعار (1400px، مقصوصة الهوامش) — تُستخدم في الوضع الفاتح |
| `assets/logo-dark.png` | نسخة معكوسة للوضع الليلي (الحبر الكحلي → فاتح، البرتقالي كما هو) |
| `assets/favicon.png` | أيقونة المتصفح (512×512) |

## المواصفات

- عربية بالكامل مع اتجاه `rtl`.
- تصميم متجاوب (جوال / لوحي / سطح مكتب).
- دعم الوضع الليلي تلقائيًا عبر `prefers-color-scheme`، وتبديل نسخة الشعار عبر `<picture>`.
- روابط تواصل مباشرة: `mailto:` للبريد و `tel:` للهاتف.
- احترام `prefers-reduced-motion` لتعطيل الحركة عند الحاجة.

## التشغيل

الصفحة ثابتة بالكامل — يكفي فتح `index.html` مباشرة، أو رفع محتوى المجلد على أي استضافة ثابتة
(GitHub Pages، Netlify، Vercel، أو استضافة عادية).

## تحديث الشعار

عند تغيّر الشعار الرسمي: استبدل `assets/logo-mark.png`، ثم أعد توليد النسخ المشتقة الثلاث
(`logo.png` و `logo-dark.png` و `favicon.png`) — وهي مجرد قصّ للهوامش وتصغير، مع عكس لون
الحبر غير البرتقالي في النسخة الليلية.
